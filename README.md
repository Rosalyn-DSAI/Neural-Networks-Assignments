## About This Repository

This repository contains assignments completed for **CS 5720: Neural Networks**.

The assignments cover the implementation and application of different neural network concepts using Python and related machine learning and deep learning libraries. Each assignment is organized into its own folder and contains the code, datasets or supporting files where applicable, results, visualizations, and written explanations required for the assignment.

The repository also documents my progression through neural network concepts, from the fundamentals of artificial neural networks to more advanced deep learning architectures.

---

## Topics Covered

The assignments in this repository explore topics such as:

* Perceptrons and basic neural network concepts
* Activation functions
* Forward propagation and backpropagation
* Neural network training and evaluation
* Training, validation, and test datasets
* Overfitting and model generalization
* Cross-validation and hyperparameter selection
* TensorFlow and Keras
* TensorBoard for monitoring model training
* Convolutional Neural Networks (CNNs)
* Convolution, filters, padding, and pooling
* Recurrent Neural Networks (RNNs)
* Long Short-Term Memory (LSTM) networks
* Sequence modeling and text generation

Additional topics will be added as the course progresses.

## Technologies and Tools

The assignments in this repository primarily use:

* **Python** - programming language used for neural network implementation and analysis
* **Jupyter Notebook / JupyterLab** - development environment used to write, run, and document code
* **TensorFlow** - deep learning framework used to build and train neural network models
* **Keras** - high-level neural network API used with TensorFlow
* **TensorBoard** - visualization tool used to monitor model training and performance
* **NumPy** - numerical computation and array manipulation
* **Pandas** - data loading and manipulation where required
* **Matplotlib** - visualization of results, model performance, and other outputs
* **Scikit-learn** - data preprocessing, model evaluation, and other machine learning utilities where applicable

The specific libraries required for each assignment are documented within the corresponding assignment folder or notebook.

## Running the Assignments

Most programming assignments are provided as Jupyter Notebook (`.ipynb`) files.

To run an assignment:

1. Clone or download this repository.
2. Open the required assignment folder.
3. Launch Jupyter Notebook or JupyterLab.
4. Open the `.ipynb` file for the assignment.
5. Install any required libraries that are not already available in the environment.
6. Run the notebook cells in order.

For TensorFlow-based assignments, the primary environment used for this coursework currently uses **TensorFlow 2.21.0**.

Some assignments may require additional datasets or supporting files. These are included in the corresponding assignment folder when appropriate.
